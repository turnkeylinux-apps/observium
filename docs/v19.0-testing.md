# Observium 19.0 test evidence

## Source and dependency decision

Debian Trixie supplies Apache, MariaDB, PHP 8.4, Net-SNMP, RRDtool,
Python, cron, and the other runtime dependencies. Debian does not package the
Observium application. The appliance therefore installs the official
Observium Community Edition archive identified internally as version
26.1.14545, revision 14545, dated 2026-01-16.

The build pins the downloaded archive to SHA-256
`01f4bec0bb01c49afe07e26f2b3f79d4eeeabf412ce5f15193df4ed7fc77d715`.
The official archive returned ETag `"7f64b3d-651124aefd0ab"`, content length
133581629, and last-modified time `Tue, 05 May 2026 13:47:48 GMT` during source
selection. The installed source record binds these values to the runtime
version metadata.

`turnkey-update-observium --check` compares the installed identity with the
official CE archive metadata. `--apply --dry-run` exercises the same decision
path without changing the appliance. A real `--apply` downloads into a private
temporary directory, rejects paths outside the `observium` archive root,
validates the internal Community Edition channel and version metadata, backs
up the database and configuration, preserves application data, applies schema
updates and rediscovery, and records the downloaded digest.
